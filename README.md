# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` - главная страница
- `css/style.css` - файл стилей
- `images/` - папка для изображений
- `.gitignore` - список файлов, исключённых из Git
- `README.md` - описание проекта

## Постановка контрольной работы №2

Тема контрольной работы №2: «Flexbox и Grid: адаптивная раскладка страниц».

В рамках контрольной работы необходимо разработать адаптивную раскладку страниц учебного сайта интернет-магазина или каталога услуг с использованием современных инструментов CSS-раскладки.

Проект должен включать:

    - шапку сайта с навигацией на Flexbox
    - блок популярных товаров или услуг, выстроенный в сетку на Grid
    - карточку товара с внутренней раскладкой на Flexbox
    - боковую панель или информационный блок
    - футер с несколькими колонками
    - адаптивную вёрстку для трёх разрешений: мобильного, планшетного, десктопного
    - медиа-запросы для изменения количества колонок в сетке
    - одинаковую высоту карточек товаров в сетке
    - центрирование элементов через Flexbox
    - оформление основных блоков страницы в едином стиле
    - сохранение семантической HTML-разметки и внешнего CSS-файла

## Постановка контрольной работы №3

Тема контрольной работы №3: «БЭМ: рефакторинг CSS-архитектуры проекта».

В рамках контрольной работы необходимо выполнить рефакторинг CSS-архитектуры учебного сайта с применением методологии БЭМ и подготовить проект к масштабированию.

Проект должен включать:

    - приведение имён классов к БЭМ-нотации (block__element--modifier)
    - разделение стилей на независимые блоки: header, nav, hero, product-card, form, footer
    - отказ от вложенных селекторов и id в CSS
    - использование модификаторов для вариантов одного и того же блока
    - вынос повторяющихся значений в CSS-переменные
    - единую систему отступов, скруглений и цветов
    - согласованную структуру файла css/style.css с разделами по блокам
    - отсутствие конфликтов специфичности между блоками
    - сохранение всех ранее реализованных состояний (:hover, :focus-visible, :disabled)
    - сохранение семантической HTML-разметки
    - сохранение адаптивной раскладки из КР №2
    - читаемый и документированный CSS-файл

## Постановка контрольной работы №4

Тема контрольной работы №4: «JavaScript: интерактивность и работа с DOM».

В рамках контрольной работы необходимо добавить на учебный сайт интерактивность средствами JavaScript: работу с DOM, обработку событий, динамическое изменение содержимого и расширенную клиентскую валидацию.

Проект должен включать:

    - вынесение всего JavaScript-кода в отдельный файл js/main.js
    - подключение скрипта через <script defer>
    - обработку событий click, submit, input, change
    - открытие и закрытие модального окна через <dialog> и методы showModal() / close()
    - динамическое заполнение скрытого поля данными из data-* атрибутов
    - расширенную валидацию формы: required, pattern, minlength, проверка email и телефона
    - визуальную подсветку ошибочных полей через aria-invalid
    - вывод сообщений об успешной отправке формы
    - сброс формы после успешной отправки
    - фильтрацию или сортировку карточек товаров на стороне клиента
    - динамическое изменение DOM: добавление, удаление и обновление элементов
    - обработку клавиатурных событий (например, закрытие модалки по Escape)
    - корректную работу интерфейса без перезагрузки страницы
    - сохранение семантической HTML-разметки, внешнего CSS-файла и БЭМ-структуры классов

- структурированный файл `css/style.css`.
